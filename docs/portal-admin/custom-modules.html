Custom Modules

Custom Modules let you create your own sets of questions tailored to the unique needs of your organization. These modules give you the flexibility to explore specific topics, moments, or challenges that are important to your team right now.

For a quick overview, check out this short tutorial:

Create Module​

The Custom Modules page shows all the modules your organization has created. To start a new one, just click the Create Module button at the top of the page.

Name​

Give your module a clear and meaningful name—something that helps others quickly understand what the questions are about. This name will also be used in reports when reviewing results.

Description​

Use the description field to add a little more context. This can be especially helpful for teammates who are scheduling modules and deciding which one to use.

Questions​

You can add as many questions as you'd like to a module—but keep in mind: more questions means more time needed to collect answers. We recommend scheduling your module to run for more working days than you have questions. That way, users who miss a day still have time to catch up.

tip

sayhii uses a scale from "Strongly Disagree" to "Strongly Agree," so it's best to phrase your questions as statements people can agree or disagree with.

You can add questions one by one or upload a full list. Once you're done, click the CREATE button to save your module. Don’t worry—you can come back and make edits later.

Module Actions​

Once your modules are created, you can schedule, edit, or delete them.

Edit​

Editing a module takes you back to the familiar module creation screen. You can update the name, tweak the description, or add/edit individual questions.

warning

If a module has already been scheduled and users have started answering questions, we recommend not editing or deleting individual questions—this could impact your data and insights.

Delete​

If needed, you can delete a custom module. However, once answers have been collected, it’s usually better to leave the module in the system for future reference.

warning

You can't delete a module that's currently scheduled. Remove the schedule first if you need to delete it.

info

Deleting a module does not remove any answers already collected.

Schedule​

Custom Modules are scheduled for specific time windows.

  • Only one custom module can be scheduled for a given date range.
  • Users will be asked one question per day—there’s no need to “catch up” like with regular sayhii questions.
  • sayhii will recommend a schedule length based on the number of questions, but you can adjust the duration as needed.

You can schedule a module from the action menu on the Custom Modules page, or from the list available on the Question Plan page.
