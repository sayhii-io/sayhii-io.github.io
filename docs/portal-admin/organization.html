Organization

The Organization page lists all users currently configured in your sayhii environment. From here, you can filter users, check their status, and take action—like enabling, disabling, or removing individual accounts.

User Information​

Each user in the list displays the following details:

  • Name – First and last name of the user
  • Email – Email address provided to sayhii
  • App Role – Most users have the role User. Those with the role Admin have access to the admin portal.
  • Active – Indicates whether the user has completed registration on at least one device
  • Sync w/ AD – Shows whether the user was added via file upload or integration
  • Device ID – A comma-separated list of devices the user has registered to answer questions
  • Manager Name – The user’s manager (if applicable and participating)
  • Manager Email – Email address of the manager (may be blank if missing)
  • Department – Department assigned to the user
  • Disabled – Indicates if the user has been disabled. Disabled users can’t log into the portal or answer questions

You can filter and sort the table to quickly locate users and take the right action.

Filter​

There are two ways to filter the user list:

  1. Include Disabled Users – Use the checkbox above the list to toggle whether disabled users are shown. By default, they're hidden.
  2. Column Filters – Use the FILTERS icon at the top of the list to select a column and filter value. Alternatively, click the triple-dot icon in any column header to apply filters directly to that column.

Sort​

Click any column header to sort the table by that column. Clicking again reverses the sort order. You can also use the triple-dot menu in the column header to fine-tune the sorting behavior.

User Actions​

Hover over a user’s row to reveal action icons in the leftmost column.

Admin Permissions​

The shield icon lets you toggle admin rights. You’ll be prompted to confirm the change, and the user will receive an email notification if their admin status is updated.

Enable/Disable​

The person icon lets you toggle whether a user is enabled. A filled icon means the user is active; clicking it will disable them. An outlined icon means the user is disabled; clicking it will re-enable them.

Delete​

Click the trashcan icon to remove a user from sayhii. This disables their account but does not delete their historical responses. The user will appear as "disabled" in any future reports.

tip

If your organization uses an HRIS integration, users will be automatically removed from sayhii when marked as terminated or removed in the HRIS. If you need to remove someone from sayhii without affecting your HRIS data, consider disabling the user instead of deleting them. Deleted users may be recreated by the HRIS sync.
