User File Management

If you can't link sayhii to an HRIS, you can manage your list of users in sayhii using our file upload feature.

When you upload a user list, the User Identifier column is required to provide a unique identifier for a user.

  • A new user is created for each row in the table that does not match an existing user record with the same User Identifier
  • For each row that matches an existing user, the user record is updated to match the information included in the newly uploaded file
note

After uploading the file, you should see a pop-up note at the bottom left of the screen that lists the number of users added and updated from the file.

CSV Format​

sayhii expects your uploaded list of users to be a properly formatted CSV file. You can use double quotes to surround strings that my contain commas. The following table lists the User Attributes that can be included in the CSV file. Only two of the columns are actually required, the user identifier and the email address for the user.
