App Features

The sayhii app is a desktop application designed to ask users questions.

Authentication​

When users answer questions, we need to know who is answering the question to align the answers with the right organization and demographics. We want to minimize the user's interaction with the identity provider, but we do want to insure that the right person is answering the questions.

Regardless of the identiy provider used, we store a token that allows the user to answer questions on a daily basis without being required to re-authenticate every time they interact with the application.

Regardless of the authentication method used, the first step in authentication is to provide your work email address.

sayhii Platform​

The default built-in authentication provider only requires that user information be provided through an HRIS integration or CSV upload. Once the users have been uploaded, users can sign in to the app or the portal using the email address provided in the user list and clicking on the link sent to the user in the confirmation email.

info

When relying on the builtin authentication mechanism, a common error seen on the desktop app is "Invalid Organization Join Key". This usually means that no user exists with the provided email address. Sometimes this happens when users provide a different email address than the organization uploaded.

Single Sign-On​

Configuring Single Sign-on requires a connection to the corporate Identity Provider. Your IT department will have helped with this configuration.

After providing the email address, the app will open a separate window to allow you to enter your corporate credentials. You may also be asked to authorize the sayhii app to read basic information from your corporate identity provider.

Registration​

After authentication is complete in the app, your organization may require you to register by answering a number of demographic questions. sayhii is dedicated to maintaining your anonymity and making sure that none of your answers are reported back to the organization. Part of the way your data can still be shared with the organization without revealing your identity is by averaging your responses with others with the same demographics.

When using the sayhii Platform authentication method, your confirmation email will be sent after you complete registration if required by your organization.

Daily Question(s)​

After you have completed authentication and registration (if required), you're ready to start answering questions.

The sayhii application is notified each time the user logs in, unlocks their computer, or wakes up their machine from sleep. In any of these cases, the application checks how long it has been since the user last answered a question, if it has been a number of hours, the app contacts the sayhii cloud to see if the user should receive a new question. If a question is available, the app displays the question and awaits the users response.

On a typical day, users should expect 1 or 2 questions to be presented. If you have been out of the office for a few days, you may be asked a few more questions each day to help you "catch up" for the missed questions.

Multiple devices​

You may register and answer questions from multiple machines. Each day you will only be expected to answer questions on one device. In rare instances, it may be possible that you will receive the same question on multiple devices on the same day.
